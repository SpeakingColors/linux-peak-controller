# Mockups

Interactive HTML mockups of Peak controller. Open any file in a browser, keep `support.js` next to it. Knobs, faders and buttons respond, but nothing makes sound or talks to hardware yet. Fonts load from Google Fonts when online.

- [Peak](mockups/Peak.dc.html)
- [PeakDeep](mockups/PeakDeep.dc.html)
- [PeakLib](mockups/PeakLib.dc.html)
